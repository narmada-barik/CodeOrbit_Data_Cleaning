# CodeOrbit Data Cleaning

## Project Title
Data Cleaning using Excel

## Technologies Used
- Microsoft Excel

## Description
This project focuses on cleaning a sample sales dataset.
The dataset was checked and cleaned for duplicate records,
missing values, and formatting issues.

## Data Cleaning Steps
1. Removed duplicate records.
2. Handled the missing Rating value.
3. Handled the missing Quantity value.
4. Standardized product names.
5. Checked and maintained a consistent Order Date format.

## Final Result
The cleaned dataset is organized and ready for further data analysis.
